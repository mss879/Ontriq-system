# Create a login on the Team page

Anyone with `users.manage` can add a person on the spot from Team, Add member, Create a login: name, email, designation and a password. The person can sign in straight away, with no invitation or email.

- A password is suggested, and can be typed instead. It meets the same rules as every other password here. It is shown once, to copy and share, and is never stored in the clear.
- The membership is written as the signed-in admin, so the role rules and audit log apply, and only a Super Admin can add a Super Admin. If that step fails, the new login is removed again.
- The account menu has Change password, so the person can replace the shared password after signing in.
- Staff only. Client logins still go through the portal's team page.
